## 规格

### 1. `mall-seckill-service/pom.xml`（在现有基础上追加依赖）
现有：`mall-common-web`、`spring-cloud-starter-alibaba-nacos-discovery`、`spring-cloud-starter-loadbalancer`、`lombok`。
追加：
```xml
<dependency>
    <groupId>com.hyf</groupId>
    <artifactId>mall-common-mybatis</artifactId>
</dependency>
<dependency>
    <groupId>com.hyf</groupId>
    <artifactId>mall-common-redis</artifactId>
</dependency>
<dependency>
    <groupId>com.hyf</groupId>
    <artifactId>mall-common-rabbitmq</artifactId>
</dependency>
<dependency>
    <groupId>com.hyf</groupId>
    <artifactId>mall-common-security</artifactId>
</dependency>
```
- 不要加 `mall-common-feign`（本服务只被 order-service Feign 调用，自身不是 Feign 客户端）。

### 2. `src/main/resources/application.yml`（保留已有 8089 + nacos，追加以下段）
```yaml
spring:
  datasource:
    url: ${MALL_DB_URL:jdbc:mysql://localhost:3306/mall?useUnicode=true&characterEncoding=UTF-8&useSSL=false&serverTimezone=Asia/Shanghai}
    username: ${MALL_DB_USERNAME:mall_app}
    password: ${MALL_DB_PASSWORD:}
    driver-class-name: com.mysql.cj.jdbc.Driver
  data:
    redis:
      host: 127.0.0.1
      port: 6379
      password:
      database: 6
      timeout: 3000ms
  rabbitmq:
    host: localhost
    port: 5672
    username: ${RABBITMQ_USERNAME:mall_app}
    password: ${RABBITMQ_PASSWORD:}
    virtual-host: /mall
    publisher-confirm-type: correlated
    publisher-returns: true
    listener:
      simple:
        acknowledge-mode: manual
        prefetch: 1

mybatis:
  mapper-locations: classpath:mapper/*.xml
  type-aliases-package: com.hyf.mallseckillservice.entity
  configuration:
    map-underscore-to-camel-case: true

mall:
  jwt:
    secret: ${MALL_JWT_SECRET:}          # 自校验 token 用，需与网关一致（≥32 字节）
  security:
    enabled: true                        # 自动装配 TokenAuthInterceptor
    exclude-paths:
      - /internal/**                     # Feign 直连不校验（网关已拦外部访问）
```
> Redis `database` 与 `mall-marketing-service` 一致用 6（键带 `mall:` 前缀，跨库无冲突）。
