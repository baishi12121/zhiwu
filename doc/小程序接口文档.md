# zhiwu-mall 前端小程序接口文档

> 本文档基于 Apifox 在线文档（`小兔鲜儿-小程序版`）整理，记录前端 `mall-uniapp` 微信小程序端调用的全部接口契约。  
> 后端基地址：
> - 开发服务器：`https://pcapi-xiaotuxian-front-devtest.itheima.net`
> - 生产服务器：`https://pcapi-xiaotuxian-front.itheima.net`
>
> 本项目当前未对接该模板接口，仅作为前端联调时的参考契约。后续若需对接，应由后端 `mall-*` 微服务实现同名同参接口后，前端切换 `baseURL` 即可。

## 1. 通用约定

### 1.1 请求头

| 参数名 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `source-client` | header | string | 是 | 小程序端固定传 `miniapp`；App 端传 `app` |
| `Authorization` | header | string | 否 | 登录后接口必传，格式 `Authorization: <token>`；无 token 或 token 错误时返回 401 |

### 1.2 响应格式

所有接口统一返回：

```json
{
  "msg": "提示语",
  "result": "数据（结构随接口变化）"
}
```

> 部分接口（如分类列表）使用 `code + msg + result` 三段式，按接口文档实际为准。

### 1.3 状态码

| 状态码 | 含义 |
|---|---|
| 200 | 成功 |
| 401 | 未登录 / token 失效 |

### 1.4 接口清单

| 模块 | 数量 |
|---|---|
| 首页模块 | 5 |
| 热门推荐 | 4 |
| 搜索模块 | 2 |
| 商品分类 | 1 |
| 商品详情 | 2 |
| 会员登录 | 4 |
| 会员中心-个人信息 | 3 |
| 会员中心-地址管理 | 5 |
| 会员中心-订单管理 | 11 |
| 购物车 | 5 |
| 支付 | 2 |
| **合计** | **44** |

## 2. 首页模块

`GET /home/banner`

## 3. 热门推荐

> 4 个接口的请求与响应结构一致：均为 `GET /hot/{key}` + `subType / page / pageSize` + `result.subTypes[].goodsItems[].items[]`。

`GET /hot/preference` — 含「抢先尝鲜」「新品预告」两个 Tab。

### 3.2 爆款推荐-小程序

`GET /hot/inVogue` — 含「24小时热榜」「热销总榜」「人气周榜」。

### 3.3 一站买全-小程序

`GET /hot/oneStop` — 含「搞定熊孩子」「家里不凌乱」「让音质更出众」。

**响应 `result`**

| `id` | string | 活动 id |
| `bannerPicture` | string | 活动图片 |

**subTypes 元素**

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 子类 id |
| `title` | string | 子类标题 |
| `goodsItems` | object[] | 分页数据 |

**goodsItems 元素**

| 字段 | 类型 | 说明 |
|---|---|---|

## 7. 会员登录

### 7.1 小程序登录

`POST /login/wxMin`

> 需使用企业小程序 `appid`，且把微信号加入开发者列表。

**Body（application/json）**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `code` | string | 是 | `wx.login()` 获取 |
| `encryptedData` | string | 是 | `getphonenumber` 事件回调 |
| `iv` | string | 是 | `getphonenumber` 事件回调 |

**响应 `result`**

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | number | 用户 id |
| `mobile` | string | 手机号 |
| `token` | string | 后续接口调用 token，有效期 3 天 |
| `nickname` | string \| null | 昵称 |
| `avatar` | string | 头像 |
| `account` | string | 用户名 |

### 7.2 小程序登录-内测版

`POST /login/wxMin/simple`

> 模拟微信一键登录，开发学习使用。匹配手机号正则 `^1[3-9][0-9]{9}$`。

**Body（application/json）**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `phoneNumber` | string | 是 | 模拟的手机号 |

**响应 `result`**：字段同 7.1（`id` 类型为 `string`）。

### 7.3 传统登录-用户名+密码

`POST /login`

> 测试账号：`13123456789` / `123456`，仅开发学习使用。

**Body（application/json）**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `account` | string | 是 | 用户名或手机号 |
| `password` | string | 是 | 密码 |

**响应 `result`**

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | number | 用户 id |
| `mobile` | string | 手机号 |
| `token` | string | token |
| `nickname` | string | 昵称 |
| `avatar` | string | 头像 |
| `gender` | string | 男 / 女 / 未知 |
| `birthday` | string | 生日 |
| `cityCode` | string | 城市编码 |
| `provinceCode` | string | 省份编码 |
| `profession` | string | 职业 |

### 7.4 刷新 token

`PUT /login/refresh`（测试中）

> token 有效期 3 天，过期后用过期 token + 用户信息换新 token。

**Header**：`Authorization: Bearer <token>`

**Body（application/json）**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `account` | string | 是 | 用户名或手机号 |
| `id` | string | 是 | 用户 id |

**响应 `result`**：同 7.3。
