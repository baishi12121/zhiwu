## 购物车 Bug 排查与修复："加车成功但列表不显示"

### 现象
商品页加车看到"添加成功"toast，切到底部 tab 购物车页显示"购物车还是空的"，下拉刷新/重进依然空。运行端：微信小程序。

### 排查发现（MySQL 直查锁定根因）
- `user_cart` 表里**有** user_id=2 的数据（sku_id=10 耳机 299元，今天 16:38 加的），预置的 sku_id=1/sku_id=7 两条已不在（可能之前清空过）
- `selectCartList(user_id=2)` 手动跑 SQL **能查到**这条数据
- `sql_mode` 含 `ONLY_FULL_GROUP_BY`，但当前 SQL 未报错（c.id 主键函数依赖被 MySQL 识别）
- **结论：POST 写入 user_id=2 成功，但前端 GET /cart 返回空数组 → GET 请求用的 userId ≠ 2（B1：add/list userId 不一致）**
- 代码层面 add/list 都用 getCurrentUserId() 从同一 JWT sub claim 取 userId，网关与 user-service 同 secret/issuer，代码无 bug，根因在运行时 token

### 已完成的修复
